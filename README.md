# Ticket Booking Service

Учебный пет-проект для изучения Spring Boot и Apache Kafka. Реализует базовый функционал бронирования билетов с асинхронной обработкой событий.

## Стек технологий

- Java 21, Spring Boot 3.2.5
- PostgreSQL (основная БД), Liquibase (миграции)
- Redis (кэширование и Rate Limiting)
- Apache Kafka (асинхронная отправка событий)
- Lombok, Spring Data JPA, Spring AOP
- Docker Compose (для поднятия инфраструктуры)

## Что реализовано

- **Бронирование билетов**: проверка наличия мест, создание записи о брони и уменьшение остатка билетов в рамках одной транзакции
- **Асинхронность через Kafka**: после успешного коммита транзакции сервис отправляет событие о бронировании в топик Kafka
- **Гарантия консистентности**: используется `@TransactionalEventListener`, чтобы сообщение ушло в Kafka только если запись в БД действительно сохранена
- **Аудит**: отдельный Kafka Consumer читает события из топика и сохраняет их в таблицу `booking_audit` для истории
- **Оптимизация**: кэширование данных о событиях через Redis и защита API от спама с помощью кастомной аннотации `@RateLimit` (реализовано через Spring AOP)
